# Wardrobe Mobile

Cross-platform iOS and Android app built with Expo and React Native.

## Run locally

1. Install Node.js LTS.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npx expo start`.
5. Scan the QR code with Expo Go, or press `a` / `i` for an installed simulator.

## First milestone

- Mobile-first navigation and visual design system
- Digital closet with category filters and favourites
- Add clothing from the photo library
- Outfit studio with selectable pieces and saved looks (in-memory prototype)

Next milestones: persistent storage, 3D scene, weather/calendar integrations, and AI recommendations.
