# Wardrobe CLIP model assets

Upload the compatible ONNX model weights into this folder. Keep the exact filenames expected by the model configuration. Also place tokenizer and configuration files in the parent folder `poc/models/Xenova/clip-vit-base-patch32/`.

Do not upload files over GitHub's individual file size limit using the web interface. The app is configured to load model assets from GitHub Pages and will not fall back to Hugging Face.
